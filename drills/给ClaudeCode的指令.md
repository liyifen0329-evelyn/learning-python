# 贴给 Claude Code 的指令（改变教法）

在你的 learn-python 目录里打开 Claude Code，把下面这段话贴进去。  
以后每节课它都会按这个方式教。

---

```
从今天起，改一下你教我 Python 的方式。我发现自己"看得懂但写不出"，
问题在于练习方式。请你按下面三条规则来：

【规则 1 · 作业不要再给步骤提示】
以前你会在 TODO 里写"第 1 步... 第 2 步... 提示：用 len()"。
这样我是在填空，不是在写程序。
从现在起，作业只给我：【要做什么】+【期望输出长什么样】。
不要给步骤、不要给提示词、不要提醒我用哪个函数。

【规则 2 · 每节课开头先让我默写】
每次开新课前，先给我一道 3-5 分钟的小题，默写上一课的核心内容。
我写完之后你再讲新课。我卡住的地方你记下来，后面多出几道同类题。

【规则 3 · 讲完立刻出一道"变式题"】
讲完新知识点，除了原题，再出一道【条件变了但套路一样】的题。
比如原题是判断高度，变式就是判断电量；原题读 welcome.txt，变式就读 flight_log.csv。
我要练的是"这类题"，不是"这道题"。

另外：麻烦你偶尔给我一段【没有任何注释】的真实代码，让我讲每段在干嘛。
我主要以求职为主，希望你能谨记这一句在你每次上课的时候。

这一课的作业，按上面的规则重新出一遍。
```

---

## 补充：以后每节课结束后自己加一句

```
帮我从 drills/默写卡合集.md 里抽一张卡的变式题，我不看笔记做一遍，你来批改。
```

## 备注

- 卡住不要紧，**卡住才是信息**。把卡点写进 `README.md` 底部的打卡表。
- 一张卡连续两次默写都写不出来 → 那个知识点退回重学，别往前赶。
- 你的目标是 PM 岗，**"能看懂、能改、能跟工程师说清楚"就够了**，  
  不需要背下整个 Python。卡 01~09 能脱稿写出来，已经超过绝大多数 PM 候选人。
