## 卡 08 · CSV 转成"字典列表"（复习 lesson11，目前最难的一张）

读 `data/flight_log.csv`，把每一行变成字典：

```
{"time": "09:00:00", "altitude": "90", "speed": "8.5", "battery": "98"}
```

全部装进一个列表 `rows`，最后打印总数和第一条。

期望输出：
```
一共 10 条记录
{'time': '09:00:00', 'altitude': '90', 'speed': '8.5', 'battery': '98'}
```

> 这张卡的骨架（不按顺序，你自己排）：
> `rows = []` / `for line in lines[1:]` / `rows.append(row)` / `keys = ...` / `values = ...` / `{keys[0]: values[0], ...}`
>
> 排不出顺序很正常 —— 排不出就说明这一课需要重看，这正是默写要告诉你的事。
