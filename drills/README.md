# 脱稿练习 · 使用说明

> 一句话：**每天学新东西之前，先用 15 分钟把昨天学的东西从空白页重写一遍。**
> 写不出来的那一处，就是你真正没学会的地方。其他都是幻觉。

---

## 为什么你"看得懂但写不出"

看你的 lesson 文件发现的三个问题：

**1. 老师的注释把答案喂到嘴边了**

```python
# 第 2 步: 给它加上行号... 想想第 5 课学的【累加器】套路
# 第 3 步: 打印 "这个文件一共 N 行"。数行数要用第 5 课学的 len()
```

跟着这种提示填空，你用的是**认得出**（recognition）。
自己动笔要的是**想得出**（recall）。
这是两种不同的脑力，练前者不长后者。

**2. 大部分练习是"抄下来改两个地方"**

lesson6b、lesson7b 的作业是"把 summary_old 整个抄下来，只动第一行和最后一行"。
抄写只练手速，不练"从零搭结构"。

**3. 注释比代码多 → 读注释制造了"我懂了"的错觉**

你 lesson12 有 9.5KB，其中真正在干活的代码不到 15 行。
读的时候顺，是因为你在读中文说明，不是在读代码。

## 三个动作

### 动作一：隔夜默写（最重要）

- 学完新课后**当天不要重做**。
- **第二天开始学之前**，新建一个空文件 `redo_XX.py`，凭记忆重写昨天的核心代码。
- 规则：**不许打开昨天的文件，不许翻笔记。** 实在想不起来就在文件里写一行注释 `# 卡住：不知道怎么读文件`，然后**跳过往下写**。
- 写完再打开昨天那份对比，用 `diff` 或肉眼看差在哪。

那条 `# 卡住：xxx` 就是你的**真漏洞清单**，只补这些点。

### 动作二：裸读（练"看懂代码"，直接对口求职）

- 复制一份 lesson 文件，删掉**所有注释**（`#` 开头的行）。
- 看着裸代码，用自己的话讲出每一行在干嘛。讲不出来 = 没看懂。

理由：你求职是 PM 岗，将来要看的是同事和 AI 写的代码 —— **那些代码没有中文注释**。
现在就练裸读，比学新语法更值钱。

### 动作三：变式（换个条件再写一遍）

新手练的是"这道题"，高手练的是"这类题"。
每一课写完，改一个条件重来：

| 原任务 | 变式 |
|---|---|
| 读 welcome.txt | 读 flight_log.csv |
| 判断高度是否超限 | 判断电量是否足够返航 |
| 求高度的平均值 | 求速度的最大值 |
| 数据是 6 条 | 数据只有 1 条 / 0 条（边界） |

## 默写卡

见 `默写卡合集.md`。规则：

1. 卡上**只有任务和输出长什么样**，没有步骤提示（有提示就白练了）。
2. 一次只做一张卡，做完一张再翻下一张。
3. 卡住就写 `# 卡住：...` 然后继续，别当场翻书。
4. 写完再对照原 lesson 文件。
